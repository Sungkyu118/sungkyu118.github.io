# Vue 포스팅 로드맵 설계

작성일: 2026-07-04

## 목적

이 문서는 `sungkyu118.github.io` 블로그에서 Vue 카테고리 글을 장기적으로 작성하기 위한 주제 로드맵입니다. 목표는 단순히 Vue 문법을 빠르게 나열하는 것이 아니라, 입문자가 실제 프로젝트를 만들면서 자주 막히는 지점까지 함께 설명하는 시리즈를 구성하는 것입니다.

Vue는 처음에는 `template`, `ref`, `v-if`, `v-for` 같은 문법이 쉬워 보이지만, 실제 프로젝트로 들어가면 컴포넌트 설계, 상태 관리, 라우팅, API 연동, 인증, 테스트, 성능, 배포 같은 주제가 빠르게 연결됩니다. 그래서 이 로드맵은 기초 문법에서 시작해 실무형 프론트엔드 개발 흐름으로 자연스럽게 확장되도록 구성합니다.

## 작성 기준

- 모든 글은 한글로 작성합니다.
- 말투는 친절한 어미를 사용하고, 입문자가 옆에서 설명을 듣는 느낌으로 씁니다.
- 각 포스트는 가능하면 3000자 이상을 목표로 합니다.
- 단순 요약형 문체를 피하고, 왜 필요한지, 언제 쓰는지, 언제 쓰면 안 되는지까지 설명합니다.
- 코드 예시는 가능한 한 손으로 따라 칠 수 있는 수준으로 구체적으로 작성합니다.
- 개념 설명 뒤에는 실습 예시, 흔한 에러, 디버깅 방법, 실무 유의사항을 함께 넣습니다.
- 시리즈 글끼리는 본문 중간과 하단에서 내부 링크를 적극적으로 연결합니다.
- 하단 관련 글 추천 이유는 짧은 한 줄이 아니라, 왜 이어서 읽어야 하는지 길고 친절하게 설명합니다.

## 시리즈 구성 전략

Vue 시리즈는 처음부터 고급 기능으로 뛰지 않고, 독자가 작은 화면 하나를 만들고, 컴포넌트로 나누고, API를 붙이고, 라우팅과 상태 관리를 확장한 뒤, 테스트와 운영까지 이어지는 흐름을 따릅니다.

초반부는 Vue를 처음 접하는 독자가 개발 환경을 만들고 화면을 직접 바꿔보는 데 집중합니다. 중반부는 컴포넌트, Composition API, Router, Pinia, API 연동처럼 실제 프로젝트에서 매일 마주치는 주제를 다룹니다. 후반부는 테스트, 성능 최적화, TypeScript, 설계, Nuxt까지 확장해서 "Vue를 쓸 줄 안다"에서 "Vue 프로젝트를 운영 가능한 형태로 만들 수 있다"로 넘어가도록 설계합니다.
