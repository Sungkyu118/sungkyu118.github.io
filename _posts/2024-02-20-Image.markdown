# Flutter Image 등록 및 사용: assets, pubspec.yaml, 에러 해결

> Flutter에서 이미지 asset을 등록하고 pubspec.yaml 설정, 경로 오류, 렌더링 문제를 해결하는 방법을 정리합니다.

Flutter 앱에서 이미지는 로고, 아이콘, 프로필 사진, 배너, 빈 상태 화면 등 거의 모든 UI에서 사용됩니다. 그런데 로컬 이미지를 처음 넣을 때는 생각보다 자주 막힙니다. 파일은 분명히 프로젝트 안에 있는데 `Unable to load asset` 에러가 나거나, `pubspec.yaml` 들여쓰기 때문에 assets 등록이 무시되는 경우가 많습니다.

이 글에서는 로컬 이미지 assets 등록, `Image.asset` 사용법, 이미지 비율 조정, 네트워크 이미지 처리, 자주 발생하는 에러를 단계적으로 정리합니다.

## assets 폴더 만들기

먼저 프로젝트 루트에 이미지 폴더를 만듭니다.

```text
my_app/
  assets/
    images/
      logo.png
      banner.png
  lib/
  pubspec.yaml
```

폴더 이름은 자유롭게 정할 수 있지만, 프로젝트 전체에서 일관되게 사용하는 것이 좋습니다. 예제에서는 `assets/images`를 사용하겠습니다.

## pubspec.yaml에 등록하기

이미지 파일을 프로젝트에 넣었다고 바로 사용할 수 있는 것은 아닙니다. Flutter에게 이 파일들을 앱 번들에 포함하라고 알려줘야 합니다.

```yaml
flutter:
  uses-material-design: true

  assets:
    - assets/images/
```

YAML은 들여쓰기에 민감합니다. `assets`가 `flutter` 아래에 있어야 하고, 탭이 아니라 공백을 사용해야 합니다. 파일 하나만 등록할 수도 있습니다.

```yaml
flutter:
  assets:
    - assets/images/logo.png
```

등록 후에는 다음 명령을 실행합니다.

```bash
flutter pub get
```

IDE를 사용 중이라면 저장 후 자동으로 실행되기도 하지만, 이미지가 보이지 않을 때는 직접 실행해보는 것이 좋습니다.

## Image.asset 사용하기

등록한 이미지는 `Image.asset`으로 불러옵니다.

```dart
Image.asset('assets/images/logo.png')
```

크기를 지정할 수도 있습니다.

```dart
Image.asset(
  'assets/images/logo.png',
  width: 120,
  height: 120,
)
```

이미지는 부모 위젯의 제약에 따라 표시 크기가 달라질 수 있습니다. 카드나 배너 안에 넣을 때는 width, height, fit을 함께 지정하는 편이 안전합니다.

## BoxFit 이해하기

이미지 원본 비율과 표시 영역의 비율이 다르면 어떻게 맞출지 결정해야 합니다. 이때 `fit`을 사용합니다.

```dart
Image.asset(
  'assets/images/banner.png',
  width: double.infinity,
  height: 180,
  fit: BoxFit.cover,
)
```

`BoxFit.cover`는 영역을 꽉 채우되 일부가 잘릴 수 있습니다. 배너나 썸네일에 자주 사용합니다. 반대로 이미지 전체가 잘리지 않아야 한다면 `BoxFit.contain`을 사용합니다.

```dart
Image.asset(
  'assets/images/logo.png',
  width: 160,
  height: 80,
  fit: BoxFit.contain,
)
```

이미지가 이상하게 늘어나거나 잘린다면 대부분 `fit` 설정을 먼저 확인하면 됩니다.

## 둥근 이미지 만들기

이미지 모서리를 둥글게 만들고 싶다면 `ClipRRect`를 사용합니다.

```dart
ClipRRect(
  borderRadius: BorderRadius.circular(16),
  child: Image.asset(
    'assets/images/banner.png',
    width: double.infinity,
    height: 180,
    fit: BoxFit.cover,
  ),
)
```

`Container`에 `borderRadius`만 주면 child 이미지가 자동으로 잘리지 않을 수 있습니다. 이 내용은 [Container와 BoxDecoration 글](/flutter/containercolor)과 함께 보면 이해하기 쉽습니다.

## 네트워크 이미지 사용하기

서버에 있는 이미지는 `Image.network`로 표시할 수 있습니다.

```dart
Image.network(
  'https://example.com/profile.png',
  width: 80,
  height: 80,
  fit: BoxFit.cover,
)
```

실제 앱에서는 로딩과 실패 상태도 처리하는 것이 좋습니다.

```dart
Image.network(
  'https://example.com/profile.png',
  width: 80,
  height: 80,
  fit: BoxFit.cover,
  loadingBuilder: (context, child, loadingProgress) {
    if (loadingProgress == null) return child;

    return const SizedBox(
      width: 80,
      height: 80,
      child: Center(child: CircularProgressIndicator()),
    );
  },
  errorBuilder: (context, error, stackTrace) {
    return const SizedBox(
      width: 80,
      height: 80,
      child: Icon(Icons.broken_image),
    );
  },
)
```

네트워크가 느리거나 URL이 잘못된 경우에도 앱이 어색한 빈 공간만 보여주지 않도록 대체 UI를 제공하는 것이 좋습니다.

## Unable to load asset 해결하기

가장 흔한 에러는 다음과 같습니다.

```text
Unable to load asset: assets/images/logo.png
```

확인할 항목은 다음과 같습니다.

- 실제 파일 경로가 맞는가
- 파일명 대소문자가 정확한가
- `pubspec.yaml`에 등록했는가
- 등록 후 `flutter pub get`을 실행했는가
- 들여쓰기가 `flutter:` 아래에 맞게 되어 있는가

Windows에서는 대소문자 차이가 느슨하게 보일 수 있지만, 배포 환경에서는 `Logo.png`와 `logo.png`가 다른 파일로 취급될 수 있습니다. 경로와 파일명은 항상 정확히 맞추는 습관이 좋습니다.

## 앱 용량 주의

이미지를 많이 넣으면 앱 용량이 커집니다. 특히 원본 사진을 그대로 assets에 넣으면 필요 이상으로 용량이 커질 수 있습니다. 썸네일로만 사용할 이미지는 적절한 크기로 줄이고, 웹에서 받아도 되는 이미지는 네트워크 이미지로 관리하는 방식을 고려할 수 있습니다.

다만 핵심 로고나 오프라인에서도 반드시 보여야 하는 이미지는 assets에 포함하는 것이 안정적입니다. 어떤 이미지를 앱에 포함하고 어떤 이미지를 서버에서 받을지 용도에 따라 나누는 것이 좋습니다.

## 정리

Flutter에서 로컬 이미지를 사용하려면 파일을 넣고, `pubspec.yaml`에 assets 경로를 등록하고, `flutter pub get`을 실행한 뒤 `Image.asset`으로 불러오면 됩니다. 이미지가 보이지 않을 때는 경로, 대소문자, YAML 들여쓰기, pub get 실행 여부를 차례대로 확인하면 대부분 해결됩니다. 실무에서는 로딩 실패 처리, 비율 유지, 앱 용량까지 함께 고려해야 자연스러운 이미지 UI를 만들 수 있습니다.
